# RE06 — Disclosure statement addresses the named item

[Real estate catalog]({{ '/real-estate/' | relative_url }}) · [Evaluation and limitations]({{ '/real-estate/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/real-estate.md)

Check whether a completed property disclosure makes a statement about one named item, mentions it without answering, or omits it.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/real-estate/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Finds blank and missing disclosure items before the form goes to the other party, while the truth of each statement and legal sufficiency stay with the parties and counsel.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `disclosure_item`
- `disclosure_text`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

## Policy recorded with its option count

Review when confidence is below 0.8. With 4 options, that floor is equivalent to a top probability of 0.85; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `RE06-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "disclosure_item": "Lead-based paint",
  "disclosure_text": "Item 9, Lead-based paint or lead-based paint hazards: [ ] Known [ ] Not known [ ] Unknown (no box marked). Item 10, Asbestos: Not known. Item 14, Additional comments: Home was built in 1994. Seller has no knowledge of any lead-based paint or lead-based paint hazards in the home and has no reports or records concerning lead-based paint."
}
```

Expected label: `addressed`.

The item's own checkbox line is blank, which alone would be mentioned_without_statement, but the additional-comments text makes a 'none known' statement about lead-based paint, and the contract counts any such statement in the text as addressing the item. Mentioned_without_statement applies only when the text gives no answer anywhere.

## Code-owned responsibilities

Code iterates over the jurisdiction's list of required disclosure items, records the form revision, and sends any item not addressed back to the listing agent; the truth of a statement and the legal sufficiency of the disclosure stay with the parties and counsel.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

One re-check after the seller's agent returns a completed form.

## Verification recipe

Compare labels with a compliance reviewer's checklist on completed disclosure forms; review every item the label called addressed that the reviewer marked incomplete.

This describes required verification work, not checks already performed.

## Source inspiration

- [US EPA: Real Estate Disclosures about Potential Lead Hazards](https://www.epa.gov/lead/real-estate-disclosures-about-potential-lead-hazards) (RE-S4). A federal agency's description of the disclosure that sellers and lessors of older housing must provide about known lead-based paint and hazards, using a disclosure form. Motivates RE06 as a check that a completed disclosure makes a statement about a named item; which items a jurisdiction requires, and whether a statement is legally sufficient, stay in code and with counsel. Motivation for the design, not evidence of Jev performance.

These sources motivate the design problem and its boundaries. They do not demonstrate Jev performance on this question.
