# EL04 — Who must act on an inspection correction item

[Electrical catalog]({{ '/electrical/' | relative_url }}) · [Evaluation and limitations]({{ '/electrical/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/electrical.md)

Classify which party an inspection correction item is directed at.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/electrical/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Routes correction items to the electrical contractor, another trade, the owner, or the utility without a person re-reading every notice.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `correction_item`
- `project_roles`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

## Policy recorded with its option count

Review when confidence is below 0.8. With 5 options, that floor is equivalent to a top probability of 0.84; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `EL04-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "correction_item": "Service bonding could not be verified: the utility's seal on the meter enclosure prevents opening it to view the bonding jumper. The serving utility must remove the seal and open the enclosure before the inspector can verify; after it is opened, the electrical contractor must install the missing bonding jumper between the meter enclosure and the service disconnect and update the panel directory. Reinspection required once both are complete.",
  "project_roles": {
    "Exampleton Electric Co.": "Electrical contractor: all wiring, panels, grounding, bonding, and labeling.",
    "Example Power Cooperative": "Serving utility: owns and seals the meter enclosure and service drop; only the utility may break its seals.",
    "Sample Ridge Builders": "General contractor: framing, drywall, and site access.",
    "Owner, P. Quillfeather": "Provides property access, documents, and project decisions."
  }
}
```

Expected label: `utility`.

The item requires actions from both the utility and the electrical contractor, and the contract says to select the party that must act first; the utility's seal removal must happen before the contractor can install the bonding jumper, even though the underlying defect is electrical work.

## Code-owned responsibilities

Code sends the item to the assigned party, tracks acknowledgement, and keeps the inspector's wording unchanged. The label does not decide who pays.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

One clarification request to the inspector when the label is unknown.

## Verification recipe

Compare routing labels with how the project manager assigned correction items on closed projects; review disputed items.

This describes required verification work, not checks already performed.

## Source inspiration

- [Washington State L&I: Electrical Permits, Fees & Inspections](https://lni.wa.gov/licensing-permits/electrical/electrical-permits-fees-and-inspections/) (ES-4). A jurisdiction's public description of when electrical permits are required, fees, and inspections, including reinspection after corrections. Motivates EL03, EL04, EL05, EL06, EL08; the jurisdiction's rules stay in code.
- [NFPA 70, National Electrical Code (NFPA overview page)](https://www.nfpa.org/codes-and-standards/nfpa-70-standard-development/70) (ES-2). The installation code adopted by jurisdictions, setting requirements for circuits, protective devices, services, and panels. Motivates EL01, EL03, EL04, EL07; no article is cited and no rule is applied by the model.

These sources motivate the design problem and its boundaries. They do not demonstrate Jev performance on this question.
