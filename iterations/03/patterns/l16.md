# L16: Gate answer search on corpus answerability

Prevent a ranked candidate from being mistaken for an answer when a bounded corpus lacks one.

## State contract

Supply a compact named JSON object with these required fields:

- <code>question</code>
- <code>tagged_corpus</code>

The state is evidence, not an instruction or action channel. Keep expected labels, credentials, authority claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>answer_present</code>, <code>coverage_kind</code>.

~~~json
{
  "answer_present": {
    "type": "noul",
    "instructions": "Does tagged_corpus contain an answer or a material partial answer to question? Judge corpus coverage only; do not synthesize an answer or assume that a ranked line must be useful.",
    "criteria": {
      "true": "At least one supplied tagged passage directly answers or materially constrains the question.",
      "false": "The supplied corpus has no direct or material partial answer."
    }
  },
  "coverage_kind": {
    "type": "choice",
    "instructions": "How completely does tagged_corpus address question? This labels the corpus, not the truth of any possible answer.",
    "criteria": {
      "direct_answer": "A supplied passage directly answers the requested question.",
      "partial_answer": "A supplied passage materially constrains the question but leaves a stated part unresolved.",
      "no_answer": "No supplied passage materially answers the question.",
      "ambiguous": "The corpus contains conflicting or unclear material that prevents one coverage label."
    }
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Code stops or expands retrieval when answer_present is low or coverage_kind is no_answer or ambiguous; it ranks lines only for eligible corpora.

**Code and governance own:** Corpus construction, line IDs, retrieval, answer generation, thresholds, and source citation.

**Simpler baseline:** Always choose the highest-ranked passage.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike L07, which chooses one supplied answer-bearing span, this first asks whether the bounded corpus has an answer at all so code can refuse a forced winner.

## Limits, source, and shared skill

A no-answer result only applies to the supplied corpus and cannot prove the answer is unavailable elsewhere.
