# RE07 — Offer message states, waives, or omits contingencies

[Real estate catalog]({{ '/real-estate/' | relative_url }}) · [Evaluation and limitations]({{ '/real-estate/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/real-estate.md)

Classify whether an offer message makes the offer subject to a condition, expressly waives conditions, or says nothing about them.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/real-estate/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Fills the contingency field on an offer record from free text so the listing agent sees every offer's conditions at a glance, without ranking or judging the offers.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `offer_message`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

## Complete synthetic example

This is fixture `RE07-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "offer_message": "On behalf of my clients, please find attached an offer of $612,000 on 87 Windmere Lane. The buyers are paying cash, so there is no financing or appraisal contingency, and they have waived the inspection contingency after their walk-through. Their obligation to close is conditioned only on receiving a clear title commitment from Northgate Title (northgate-title.example) within 10 days of acceptance. We hope this makes for a clean, fast closing."
}
```

Expected label: `states_contingency`.

Despite waiving financing, appraisal, and inspection, the message makes the offer subject to a title condition, and the contract says an offer states a contingency if it is subject to any such condition even when it also waives others. 'Conditioned only on' still states a condition rather than stating none.

## Code-owned responsibilities

Code records the offer identifier, extracts the named contingency types and deadlines exactly from the signed documents, and leaves acceptance, counteroffer, and advice to the seller and licensed agents; the label never ranks offers.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; unknown messages go to the listing agent.

## Verification recipe

Compare labels with the contingency fields the transaction coordinator entered from the signed offer documents; review every offer the label marked as waiving contingencies.

This describes required verification work, not checks already performed.
