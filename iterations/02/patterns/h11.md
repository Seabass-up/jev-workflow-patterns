## State contract

Supply a small, named JSON object. Required fields:

- `item`
- `current_node`
- `children`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "Which child of `current_node` best fits `item` using only the supplied `children`? An unproblematic change request, including a visual-change request, is not itself a support issue and must be `no_match`. Choose `no_match` or `uncertain` where appropriate. The caller may preserve multiple plausible paths.",
    "criteria": {
      "access_issue": "The item concerns permission, entry, login, or access arrangement.",
      "hardware_issue": "The item concerns a physical device/component fault or replacement.",
      "software_issue": "The item concerns program, configuration, or service behavior.",
      "no_match": "The item is specific but none of the current children fits.",
      "uncertain": "The item, current node, or child definitions are insufficient or mixed."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code returns the parent category (or a retained beam) on `uncertain`, `no_match`, or below a policy confidence floor; it does not continue toward a leaf.

**Code and governance own:** Hold taxonomy tree/version, beam width, thresholds, identity, routing permission and final action.

**Baseline this improves on:** Flat leaf classifier or greedy forced-leaf traversal.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Uses hierarchy traversal and confidence backoff, rather than L09's single-node classification or H01's action-equivalence ambiguity shortcut.

## Limits and sources

A category is not a support assignment or action permission.

[Source documentation](https://docs.typesafe.ai/cookbooks/hierarchical_classification). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
