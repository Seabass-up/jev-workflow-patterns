## State contract

Supply a small, named JSON object. Required fields:

- `task`
- `bindings`
- `reference_material`
- `assembly_plan`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "How does `assembly_plan` handle the supplied task, bindings, and reference material? Classify role separation, not trustworthiness, security, or permission.",
    "criteria": {
      "consistent": "The plan keeps the task, verified bindings, and reference material in their declared roles.",
      "reference_promoted": "The plan treats reference/quoted material as a binding control without it being presented as one.",
      "binding_omitted": "A supplied binding constraint is absent from the plan's declared control lane.",
      "insufficient": "The inputs or assembly plan are missing, mixed, or too vague to compare."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Hold `reference_promoted`, `binding_omitted`, or `insufficient` plans for correction. Code must bind the actual controlling source independently.

**Code and governance own:** Prompt construction, origin verification, authority, privilege boundaries and model invocation.

**Baseline this improves on:** Concatenate every input source in arrival order.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike L08's per-text role label, this evaluates a declared multi-lane assembly plan. It is not a prompt-injection defense.

## Limits and sources

A semantically tidy assembly still needs source trust and security controls.
