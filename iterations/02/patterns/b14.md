## State contract

Supply a small, named JSON object. Required fields:

- `message`
- `date_candidates`
- `date_role`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "deadline_candidate": {
    "type": "choice",
    "instructions": "Which candidate in `date_candidates` is the date or relative expression for `date_role` in `message`? Choose only a supplied candidate. Do not calculate calendar dates.",
    "criteria": {
      "c1": "Candidate c1 is the requested deadline expression.",
      "c2": "Candidate c2 is the requested deadline expression.",
      "c3": "Candidate c3 is the requested deadline expression.",
      "no_deadline": "The message states no deadline for the named role.",
      "ambiguous": "More than one candidate could be the deadline, or their relationship is unresolved."
    }
  },
  "deadline_kind": {
    "type": "choice",
    "instructions": "How is the deadline for `date_role` expressed in `message`? Judge the language only; do not resolve calendar arithmetic.",
    "criteria": {
      "hard_deadline": "A mandatory 'by', 'no later than', or equivalent deadline is stated.",
      "target_date": "A goal, estimate, or non-mandatory target date is stated.",
      "relative_window": "A period relative to a reference date or event is stated.",
      "unclear": "No clear deadline kind is stated or the statements conflict."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** On `ambiguous`, ask which expression controls. Code resolves a selected date using a verified reference date/event and validates calendar rules before recording a deadline.

**Code and governance own:** Parse dates, time zones, business-day rules, locale, reference dates, source revision and actual schedule effects.

**Baseline this improves on:** Ask an LLM to compute the calendar date from prose.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike B05's commitment classification, this selects a named temporal expression and explicitly delegates date math to code.

## Limits and sources

The model may select the wrong span; no calendar or contractual deadline is established until code validation.
