## The useful decision

Reduce irrelevant LLM context while keeping passages that challenge the question's premise. Measure: Answer-source recall, retained contradictions, and context bytes at equal answer quality.

Required state fields: `query`, `passage`. One request evaluates one coherent state. These questions are independent; none can see another answer in its batch.

## Exact question contract (version 1)

```json
{
  "relevance": {
    "type": "score",
    "instructions": "How directly does `passage` help answer `query`? Evidence that disproves the query's premise is directly useful. Topical vocabulary alone is not an answer.",
    "criteria": [
      "Unrelated to answering the query.",
      "Related background but no concrete answer evidence.",
      "Supplies part of the information needed for the answer.",
      "Directly answers the query or directly disproves its premise."
    ]
  },
  "premise_conflict": {
    "type": "noul",
    "instructions": "Does `passage` explicitly contradict an assumption asserted by `query`? A neutral question without an asserted premise does not itself create a conflict.",
    "criteria": {
      "true": "A stated premise in the query is directly opposed by the passage.",
      "false": "No asserted premise is contradicted, or the passage does not establish such a contradiction."
    }
  }
}
```

## Consume the JSON and drill down

Read the named answer(s), validate their type and allowed values, then use the documented labels or ordered score as a proposed review signal. Do not treat the result as an executed action.

Follow-up: Broaden retrieval when no passage answers the question. Preserve mandatory sources and counterevidence outside relevance pruning.

Code owns: Retain source IDs/revisions and retrievable originals; validate tenant access, source freshness and context budgets; do not use this as an injection security boundary.

Use provisional Choice/Score confidence ≥ 0.8 and Noul ≤ 0.2 / ≥ 0.8 only as experimental review gates. A Noul near 0.5 is uncertainty, not medium intensity. Thresholds require domain-specific evaluation. Provider failure, invalid output, stale state or missing required evidence goes to review, not to an assumed default. Gate only the questions consumed by the selected branch.
