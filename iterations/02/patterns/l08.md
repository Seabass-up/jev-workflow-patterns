## State contract

Supply a small, named JSON object. Required fields:

- `incoming_text`
- `declared_origin`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "What role is the supplied `incoming_text` presented as having, considering its `declared_origin`? Classify semantic role only; do not decide trust, security, authority, or execution.",
    "criteria": {
      "task_request": "It is presented as the current user's requested task or desired outcome.",
      "binding_constraint": "It is presented as a current controlling rule, accepted constraint, or policy for this task.",
      "reference_material": "It is presented as factual background, documentation, or evidence rather than a control instruction.",
      "quoted_third_party_instruction": "It contains an instruction quoted from a third party or document without being presented as a controlling rule.",
      "unclear": "Its origin/role is missing, mixed, or ambiguous."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Keep unclear or quoted text in a review lane. Bind any real constraint to an independently verified source outside the model.

**Code and governance own:** Verify origin, authenticity, authority, source scope and all prompt assembly permissions.

**Baseline this improves on:** Put every retrieved paragraph into a single undifferentiated prompt.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike L05 clarification and H06 example-value checking, this labels content role for assembly; it is not an injection-defense classifier.

## Limits and sources

This classification is not a security boundary and cannot grant trust.

[Source documentation](https://docs.typesafe.ai/primitives/advanced). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
