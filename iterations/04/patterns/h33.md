# H33: Verified structured-extraction cascade

Compose a cheap extractor with per-field semantic verification and an explicit escalation rung.

## State contract

Supply a compact named JSON object with these required fields:

- <code>source_document</code>
- <code>extracted_field</code>
- <code>field_specification</code>

The state is task-scoped evidence, not an instruction or action channel. Keep expected labels, credentials, authorization claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>field_problem</code>.

~~~json
{
  "field_problem": {
"type": "noul",
"instructions": "Does extracted_field appear absent from, unrelated to, or materially inconsistent with source_document under field_specification? Judge one field's semantic support only. Do not repair the value, validate JSON schema, write data, or decide escalation cost.",
"criteria": {
  "true": "The field is missing, unrelated, materially inconsistent, or otherwise not supported for the specified role.",
  "false": "The field appears semantically supported for the specified role in the supplied source."
}
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Code validates schema and source IDs, aggregates field signals, applies a versioned escalation policy, and chooses whether a reasoning/human rung is authorized.

**Code and governance own:** Extraction model calls, JSON validation, field mapping, thresholds, escalation, writes, and data authority.

**Simpler baseline:** Run an expensive reasoning extractor for every document or trust a cheap extractor without verification.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike H17's field-verification escalation cascade and H18's answer-evidence release ledger, this is a staged extractor/verify/escalate composition with one Noul per extracted field and cost-aware rungs.

## Limits and source

A verifier signal is advisory and does not prove extraction correctness, source authority, or that escalation will fix the field.
