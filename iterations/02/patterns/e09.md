## State contract

Supply a small, named JSON object. Required fields:

- `operation_description`
- `failure_context`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "What retry posture is supported by `operation_description` and `failure_context`? This is an evidence classification, not permission to retry.",
    "criteria": {
      "safe_no_effect": "The evidence explicitly says the failure occurred before any side effect was committed.",
      "safe_idempotent": "A stable idempotency or deduplication mechanism is explicitly stated to make a repeat of this request non-duplicating.",
      "manual_review": "A consequential side effect may have happened and the supplied evidence does not establish safe deduplication.",
      "insufficient": "The operation, outcome, or deduplication evidence is missing or contradictory."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** For any non-safe result, fetch the idempotency record or reconcile the external effect. Never retry consequential work merely from this label.

**Code and governance own:** Check exact idempotency keys, transaction state, external provider receipt, retry budget and authorization.

**Baseline this improves on:** Retry once after every timeout.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike E07's proposed repair check, this assesses the semantic evidence supporting a specific repeat attempt.

## Limits and sources

The model cannot prove a side effect did or did not occur.
