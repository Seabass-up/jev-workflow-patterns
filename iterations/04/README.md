# Iteration 4 — final Jev question-pattern cycle

This directory contains 30 public, task-authored Jev question contracts: seven business, seven engineering, six LLM, and ten harness designs. It builds on Iterations 1–3 but does not claim global novelty, production accuracy, calibration, or operational readiness.

Start at [the catalog page](index.md), then inspect the exact [JSON catalog](catalog.json), [frozen synthetic fixtures](fixtures.json), [source/duplicate-screen receipts](results/), and [evaluation](evaluation.md).

The fixture set includes the 60 original cases and 26 development boundary cases for ten version-2 Choice contracts. First-pass misses and overlap-audit receipts are preserved; see the evaluation page before interpreting the 86/86 current selection.

All provider inputs are synthetic. Code—not Jev—owns IDs, candidate coverage, arithmetic, dates, authorization, writes, communication, and verification.
