# MR07 — What a scrutineering note concerns

[Motorsport catalog]({{ '/motorsport/' | relative_url }}) · [Evaluation and limitations]({{ '/motorsport/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/motorsport.md)

Classify whether a scrutineering note concerns a dimension, mass, material or construction, or safety equipment.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/motorsport/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Routes each note to the right crew and measurement record; whether the car complies stays with the scrutineers and the exact checks in code.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `scrutineering_note`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

## Policy recorded with its option count

Review when confidence is below 0.8. With 5 options, that floor is equivalent to a top probability of 0.84; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `MR07-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "scrutineering_note": "Note 14, car 41: helmet-to-main-hoop clearance checked with the driver seated and belted in the race seat; the gap to the underside of the hoop is to be re-measured with the new seat insert fitted before the car is released. Hoop padding is the approved type."
}
```

Expected label: `safety_equipment`.

The note raises a clearance, which is dimensional, but it concerns the roll structure, seat, and belts, which the contract lists as safety equipment; when more than one subject is raised the order selects safety_equipment first.

## Code-owned responsibilities

Code assigns the note to the responsible crew, links it to the measurement or homologation record for that subject, performs any numeric check exactly, and records the scrutineers' decision as authoritative.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; unknown notes go to the team manager.

## Verification recipe

Compare labels with how the team manager assigned a season of scrutineering notes; review every note assigned to a different crew.

This describes required verification work, not checks already performed.

## Source inspiration

- [Wikipedia: Engineering tolerance](https://en.wikipedia.org/wiki/Engineering_tolerance) (MR-S3). Defines a tolerance as the permissible limit of variation, notes that tolerances can be applied to any dimension or physical property, and that a part outside tolerance is unusable by design intent while a stated tolerance does not by itself imply compliance. Motivates MR03 (which property is constrained), MR04 (a conformance claim is distinct from an observation), and MR07 (dimensional and mass notes). Motivation only, not evidence of Jev performance.
- [Wikipedia: Racing setup](https://en.wikipedia.org/wiki/Racing_setup) (MR-S4). Lists the adjustable parameters of a racing car, such as dampers, anti-roll bars, gear ratios, tyre pressures, wing angles, toe, camber, brake bias, and ride height, and the handling trends adjustments usually produce. Motivates MR05 (a change log names one or several of these parameters), MR06 (a change is judged against a reference run), and MR07 (scrutineering notes concern the same adjustable geometry). Motivation only, not evidence of Jev performance.

These sources motivate the design problem and its boundaries. They do not demonstrate Jev performance on this question.
