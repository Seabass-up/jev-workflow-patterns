## State contract

Supply a small, named JSON object. Required fields:

- `old_schema`
- `new_schema`
- `rollout_plan`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "What compatibility posture is supported by `old_schema`, `new_schema`, and `rollout_plan`? Assess stated data/reader behavior, not semantic version numbers or an actual deployment.",
    "criteria": {
      "backward_compatible": "The change is additive or the plan explicitly keeps existing readers and stored records working without a transition reader.",
      "dual_read_required": "The representation changes and the plan explicitly requires or supplies a transition that reads both old and new forms.",
      "breaking_cutover": "A required field or representation is removed/renamed with no stated compatible reader or migration path.",
      "insufficient": "A schema, stored-data behavior, or rollout plan is absent, vague, or contradictory."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Inspect the exact schema diff and sample old records; test rollback and staged readers before deployment.

**Code and governance own:** Validate schemas, migrations, version gates, storage state, rollout ordering and deployment actions.

**Baseline this improves on:** Only compare API field names.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike E03's consumer interface check, this addresses stored-data and staged-reader compatibility.

## Limits and sources

A compatible-looking schema plan still needs executable migration tests.
