## State contract

Supply a small, named JSON object. Required fields:

- `incident_note`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "What kind of causal statement does `incident_note` make? Classify the evidence language, not whether the statement is true.",
    "criteria": {
      "observation": "It reports a measurement, log, event, or correlation without asserting a cause.",
      "hypothesis": "It proposes a possible/probable cause without a stated causal demonstration.",
      "confirmed_cause": "It explicitly cites a controlled reproduction, trace, experiment, or other stated evidence establishing the cause.",
      "conflict_or_unknown": "The note is missing, mixes incompatible causal statuses, or lacks enough wording to classify."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Label a hypothesis as such and request its discriminating evidence. Preserve observations and alternative causes.

**Code and governance own:** Run reproductions, analyze traces, establish causality and write incident conclusions.

**Baseline this improves on:** Promote the strongest-sounding sentence to root cause.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike E08's repeatability classification, this labels causal language within the incident narrative.

## Limits and sources

A model label cannot confirm that an alleged experiment actually occurred.

[Source documentation](https://docs.typesafe.ai/primitives). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
