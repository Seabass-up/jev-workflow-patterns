## State contract

Supply a small, named JSON object. Required fields:

- `request`
- `answer_plan`
- `available_evidence`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "coverage": {
    "type": "score",
    "instructions": "Rate how completely `answer_plan` addresses each named output in `request` using `available_evidence`. Assess plan coverage only; do not generate the answer or invent sources. A vague conclusion that does not name a requested output is not coverage. At the top level, the plan must identify material facts, their supplied sources, and an explicit limitation when requested.",
    "criteria": [
      "The plan does not address the request or supplies no answer/evidence plan.",
      "The plan addresses only a subset of requested outputs.",
      "The plan addresses all requested outputs but leaves a material claim, constraint, limitation, or source linkage unaddressed.",
      "The plan addresses all stated outputs and ties material factual claims to supplied evidence or explicitly names a limitation."
    ]
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** For a score below the accepted plan threshold, ask for the missing output/source/limitation or constrain the answer to what evidence supports.

**Code and governance own:** Count claim IDs, source IDs, required fields, citation formatting and final answer delivery.

**Baseline this improves on:** Generate first and inspect citations after the answer is already composed.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike L01 passage ranking and L02 individual citation checking, this judges pre-generation coverage of the complete answer plan.

## Limits and sources

A high score does not validate factual correctness or source authority.

[Source documentation](https://docs.typesafe.ai/cookbooks/citation_check). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
