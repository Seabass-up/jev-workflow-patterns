## State contract

Supply a small, named JSON object. Required fields:

- `policy`
- `proposed_action`
- `stated_effect`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "hazard": {
    "type": "noul",
    "instructions": "Does `proposed_action` directly request or propose an action that the stated `policy` expressly prohibits? Judge only the supplied text; do not infer authority or execute an action.",
    "criteria": {
      "true": "The policy explicitly forbids the action described in proposed_action.",
      "false": "The policy does not expressly prohibit the described proposed_action, or no prohibited action is described."
    }
  },
  "severity": {
    "type": "score",
    "instructions": "Rate only the supplied `stated_effect` if `proposed_action` were carried out. Do not imagine a consequence that is not stated. The caller will use this score only when the separate hazard question is high.",
    "criteria": [
      "No prohibited action or no stated consequential effect.",
      "A limited, reversible policy violation is described.",
      "A material external, data, financial, privacy, or reputational effect is described.",
      "An irreversible or high-impact effect is explicitly described."
    ]
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code combines raw values with a written policy matrix, mandatory escalation rules and a human review path. No result triggers a real-world action.

**Code and governance own:** Policy version, jurisdiction, thresholds, human authority, exact severity handling and actual response.

**Baseline this improves on:** A single opaque pass/block label.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike H07 notification materiality, this composes independent hazard and stated-severity judgments into a non-executing policy-routing matrix.

## Limits and sources

This is not a security boundary, moderation guarantee or authority to block/allow a user.
