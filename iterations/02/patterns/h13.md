## State contract

Supply a small, named JSON object. Required fields:

- `document`
- `date_role`
- `candidates`
- `reference_context`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "mode": {
    "type": "choice",
    "instructions": "How is the date for `date_role` expressed in `document`? Read text only; do not compute a date.",
    "criteria": {
      "absolute": "A complete or partial calendar expression is directly stated.",
      "relative_to_reference": "It is relative to an explicit reference date such as today or a stated date.",
      "relative_to_event": "It is relative to a named event whose date must be resolved separately.",
      "not_stated": "No date for this role is stated.",
      "ambiguous": "Competing or unclear date expressions prevent classification."
    }
  },
  "candidate": {
    "type": "choice",
    "instructions": "Which supplied candidate in `candidates` is the date expression for `date_role`? Choose only a candidate ID, `not_stated`, or `ambiguous`.",
    "criteria": {
      "c1": "Candidate c1 is the named date expression.",
      "c2": "Candidate c2 is the named date expression.",
      "c3": "Candidate c3 is the named date expression.",
      "not_stated": "No supplied candidate is a date for this role.",
      "ambiguous": "More than one candidate is plausible or the text conflicts."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code refuses resolution when mode/candidate is uncertain, required reference data is missing, or parse/validation fails. It records the source expression and resolver version.

**Code and governance own:** Calendar arithmetic, locale, time zone, business-day semantics, reference event lookup and schedule updates.

**Baseline this improves on:** Ask a model for a final calendar date in one step.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Generalizes B14's business deadline selection into a reusable date-resolution controller with explicit validation gates.

## Limits and sources

The controller needs a trusted reference context and does not establish contractual meaning.

[Source documentation](https://docs.typesafe.ai/cookbooks/date_extraction_cookbook). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
