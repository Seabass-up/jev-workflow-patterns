## State contract

Supply a small, named JSON object. Required fields:

- `case`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "For the low-stakes routing question described in `case`, what route is supported by the supplied facts? This request is one sample in a repeated stability check; do not infer permission to act.",
    "criteria": {
      "automatic": "The case explicitly meets the stated low-stakes automatic routing condition.",
      "review": "Evidence is missing, conflicting, or does not meet the automatic-routing condition."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code repeats the exact request a bounded number of times with cache disabled, retains every answer/model/version, and sends disagreement or low confidence to review. Agreement never overrides a mandatory human gate.

**Code and governance own:** Choose sample budget, compare labels, record timing/usage, apply route policy and perform actual actions.

**Baseline this improves on:** One call with one confidence threshold.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Uses repeated typed-decision agreement as a bounded stability signal, distinct from H04 reviewer disagreement; related prior work is documented, not claimed as novel.

## Limits and sources

Repeated agreement is not correctness or calibration; never use it for high-consequence automatic action.

[Source documentation](https://docs.typesafe.ai/cookbooks/consistency_choice_cookbook). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
