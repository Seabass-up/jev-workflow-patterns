# HA02 — Worked-example blank practices the wrong skill

[Human + AI catalog]({{ '/human-ai/' | relative_url }}) · [Evaluation and limitations]({{ '/human-ai/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/human-ai.md)

Check that the omitted step of a worked example elicits the explicitly selected skill.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/human-ai/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Prevents practice that asks a learner to copy an incidental detail while leaving the intended reasoning fully supplied.

This is a proposed benefit, not an observed human outcome. All fixtures on this page are synthetic. No study with people was conducted for this catalog, and the question must not be used to infer a person's traits, ability, diagnosis, or intent.

## Required named state

Supply the following named fields as the evidence packet:

- `target_skill`
- `worked_steps`
- `blank_instruction`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. Preserve the exact source revision. Any remaining insufficiency or ambiguity follows the question's `unknown` criteria; a model label cannot establish missing facts.

## Complete synthetic example

This is fixture `HA02-4`, from the **challenge** split. Its author received the question contract without the original design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "target_skill": "Select the sentence that provides evidence for a stated claim.",
  "worked_steps": "Claim: The container has a leak. Candidate A: The container is painted green. Candidate B: Water drips through a hole in the bottom. The worked example selects B and explains that the escaping water supports the leak claim.",
  "blank_instruction": "The evidence selection and explanation above are complete. Do not select another sentence. Fill the blank with the last word of the already selected sentence: _____."
}
```

Expected label: `incidental`.

Completing the blank only requires copying a word from evidence that has already been selected. The missing step does not require choosing supporting evidence.

## Code-owned responsibilities

Code selects approved curriculum objectives and preserves step IDs. A tutor, not this label, chooses the next lesson or assessment.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

If ambiguous, obtain one approved description of what the blank requires; otherwise return review without adapting the curriculum.

## Verification recipe

Have an educator identify the skill actually demanded by each blank, then compare judgments including multi-skill and copying cases.

This describes required verification work, not checks already performed. Separate agreement with synthetic expected labels from successful execution of the real workflow and from any measured benefit to a person.
