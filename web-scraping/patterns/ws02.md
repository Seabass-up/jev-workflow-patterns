# WS02 — Page excerpt contains the target record type

[Web data catalog]({{ '/web-scraping/' | relative_url }}) · [Evaluation and limitations]({{ '/web-scraping/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/web-scraping.md)

Classify whether a page excerpt contains at least one record of the type the extractor targets.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/web-scraping/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Keeps extractors from parsing pages that hold no target records and flags crawls that drifted into another record type, without a person opening each page.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `target_record_type`
- `page_excerpt`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

## Policy recorded with its option count

Review when confidence is below 0.8. With 4 options, that floor is equivalent to a top probability of 0.85; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `WS02-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "target_record_type": "Job listing: one open position presented for applicants, with a job title, the hiring employer, a location or remote status, and a way to apply.",
  "page_excerpt": "Larkspur Analytics to add 40 engineering jobs at Portland office. By Staff Reporter, 12 September 2026. The data firm said on Thursday it will hire about 40 software and data engineers over the next year as it expands its streaming platform. A spokesperson said postings would appear on the company careers site in stages, with the first roles focused on pipeline reliability. The announcement follows a funding round closed in June. Related: Regional tech hiring cools in second quarter."
}
```

Expected label: `different_record_type`.

The excerpt is a news article about hiring, with a headline, byline, date, and reporting, not a job listing: no position is presented with a title, location, and application route. The contract classifies records of another kind, such as an article when a listing is targeted, as different_record_type.

## Code-owned responsibilities

Code selects which part of the page becomes the excerpt, counts records with the extractor, and records the page URL and fetch hash; the label decides only whether parsing proceeds.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; a different_record_type label goes to the crawl owner to check the seed URLs.

## Verification recipe

Sample crawled pages, have a maintainer mark whether they contain target records, and compare; review pages labeled no_record that the extractor later parsed successfully.

This describes required verification work, not checks already performed.
