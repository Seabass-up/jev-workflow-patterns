## State contract

Supply a small, named JSON object. Required fields:

- `question`
- `candidates`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "Which supplied candidate span directly contains an answer to `question`? Choose only a candidate ID, `not_present`, or `ambiguous`. Do not combine text from multiple spans or infer an answer absent from them.",
    "criteria": {
      "s1": "Candidate span s1 directly answers the question.",
      "s2": "Candidate span s2 directly answers the question.",
      "s3": "Candidate span s3 directly answers the question.",
      "not_present": "None of the supplied spans directly answers the question.",
      "ambiguous": "More than one span directly answers incompatibly or the intended answer cannot be selected."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** On `not_present`, broaden retrieval. On `ambiguous`, preserve both source IDs and ask a focused question or show the conflict. Code copies the selected verbatim span.

**Code and governance own:** Build candidate set, verify offsets/revisions, quote verbatim, format citations and authorize source access.

**Baseline this improves on:** Rank documents by topical relevance and let a generator paraphrase freely.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike L01's relevance/ranking and L02's claim verification, this selects one exact answer-bearing span before answer generation.

## Limits and sources

Candidate coverage is caller-owned; Jev cannot select an omitted source.
