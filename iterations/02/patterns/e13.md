## State contract

Supply a small, named JSON object. Required fields:

- `invariant`
- `telemetry_description`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "How does `telemetry_description` observe the stated `invariant`? Judge the measurement relationship, not whether current values are healthy. Do not call an unspecified 'normal' or 'healthy' metric a proxy unless the text identifies both what it measures and its relationship to the invariant.",
    "criteria": {
      "direct": "The telemetry explicitly measures the invariant's stated success/failure condition.",
      "proxy_only": "The telemetry measures a related signal but not the invariant itself.",
      "unobservable": "The description explicitly says no event, metric, or trace represents the invariant.",
      "insufficient": "The invariant or telemetry description is absent, vague, or impossible to relate."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** For proxies, add a direct event/metric or explicitly record the gap. Query live telemetry only through approved observability tools.

**Code and governance own:** Define invariant IDs, collect metrics/traces, calculate SLOs and act on alerts.

**Baseline this improves on:** Treat high traffic or low errors as proof of any desired behavior.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike E02's test coverage and E04's next diagnostic source, this evaluates production observability against a named invariant.

## Limits and sources

A direct signal can still be delayed, sampled, broken, or misinterpreted.

No single external source is assigned to this task-authored combination. It is not a claim of global novelty.
