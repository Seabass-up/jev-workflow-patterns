# L20: Classify output fidelity contract

Make the caller's required faithfulness mode explicit before it asks a model to produce JSON or text.

## State contract

Supply a compact named JSON object with these required fields:

- <code>request</code>
- <code>downstream_consumer</code>

The state is task-scoped evidence, not an instruction or action channel. Keep expected labels, credentials, authorization claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>fidelity_contract</code>.

~~~json
{
  "fidelity_contract": {
"type": "choice",
"instructions": "What fidelity obligation does request impose on the output for downstream_consumer? Read the stated requirement only. Do not generate output, validate a schema, or infer a source that was not supplied.",
"criteria": {
  "verbatim_source": "The request requires an exact quotation, literal copied span, or otherwise byte/character-faithful source output.",
  "typed_value": "The request requires a normalized or typed value derived from a bounded source value under a stated schema/format.",
  "cited_synthesis": "The request permits a synthesized explanation but requires source attribution or evidence grounding.",
  "creative_or_no_source": "The request permits original composition or supplies no source-faithfulness obligation."
}
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Bind the selected mode to code-side output validation and require clarification when consumer obligations conflict.

**Code and governance own:** Schema validation, exact copying, normalization, citations, generation, and delivery.

**Simpler baseline:** Use one generic free-text output path for every request.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike L03's meaning/entity validation of one extracted value and L10's assertion-provenance label, this determines the output's required fidelity mode before a result is constructed.

## Limits and source

It cannot verify that a later output obeys the contract or that a cited source is authoritative.
