# H26: Answerability-then-selection retrieval controller

Make corpus coverage a stop condition before ranking creates a forced answer candidate.

## State contract

Supply a compact named JSON object with these required fields:

- <code>query</code>
- <code>candidate_corpus</code>

The state is evidence, not an instruction or action channel. Keep expected labels, credentials, authority claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>controller_route</code>.

~~~json
{
  "controller_route": {
    "type": "choice",
    "instructions": "What retrieval-controller route is supported by the stated query and candidate_corpus coverage? This selects the next bounded workflow branch, not an answer or source authority.",
    "criteria": {
      "rank_eligible": "The corpus explicitly contains answer-bearing candidates that can proceed to a ranking stage.",
      "expand_or_retrieve": "The corpus explicitly lacks an answer or is only a known incomplete shortlist requiring expansion.",
      "preserve_conflict_for_review": "The corpus explicitly contains material conflicting answer evidence that must not be collapsed into one forced answer.",
      "insufficient": "The supplied state does not establish a safe route."
    }
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Code runs an answerability gate, ranks only eligible candidate IDs, and retains counterevidence in a separate review lane.

**Code and governance own:** Retrieval, corpus scope, ranking, candidate IDs, thresholds, citation, and answer generation.

**Simpler baseline:** Choose the highest-ranked retrieved passage regardless of corpus coverage.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike L16's corpus answerability question itself, this controller combines coverage with a subsequent ranking or expansion branch and preserves conflict.

## Limits, source, and shared skill

It cannot make an incomplete corpus complete or establish source authority.
