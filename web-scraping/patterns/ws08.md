# WS08 — Page is an item page, a listing page, or navigation

[Web data catalog]({{ '/web-scraping/' | relative_url }}) · [Evaluation and limitations]({{ '/web-scraping/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/web-scraping.md)

Classify whether a page presents one record in full, a set of records in summary, or neither, so the crawler routes it to the right extractor.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/web-scraping/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Keeps item extractors off listing and navigation pages and finds the item pages a crawl can treat as a record's source; canonical URL selection stays in code.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `page_excerpt`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

Review when confidence is below 0.8. With 4 options, that floor is equivalent to a top probability of 0.85; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `WS08-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "page_excerpt": "Title: Search: brass hinges - Hollowell Hardware. H1: Search results. Main: We couldn't find anything for \"brass hinges\" (0 results). Check the spelling or try a broader term. [Form: keyword field, department dropdown, Search button]. Browse departments: Door hardware, Fasteners, Hand tools, Garden. Footer: Help, Stores, Privacy."
}
```

Expected label: `navigation_or_utility`.

Although this is a search results page, its main content presents no record in summary or in full, only a no-results message, a search form, and a department menu; the contract's listing_page requires a set of records, so the page is navigation_or_utility.

## Code-owned responsibilities

Code reads the canonical link element and URL parameters exactly, chooses the canonical URL for each record, routes item pages to the item extractor and listing pages to the link collector, and never follows sign-in or access-restricted pages.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; navigation_or_utility pages are not extracted.

## Verification recipe

Sample crawled URLs, have a maintainer classify each page, and compare; review listing pages the label called item pages first.

This describes required verification work, not checks already performed.
