# H27: Entity alignment merge-hold controller

Make a model alignment judgment a triage signal, never an automatic merge.

## State contract

Supply a compact named JSON object with these required fields:

- <code>candidate_pair</code>
- <code>field_evidence</code>
- <code>merge_policy</code>

The state is evidence, not an instruction or action channel. Keep expected labels, credentials, authority claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>merge_route</code>.

~~~json
{
  "merge_route": {
    "type": "choice",
    "instructions": "What merge-handling route is supported by candidate_pair, field_evidence, and merge_policy? Classify the route only. Do not merge, edit, or delete an entity.",
    "criteria": {
      "independent_identity_check": "The pair appears alignable but policy requires an independent deterministic identity check before a link.",
      "curator_review": "The supplied fields are related, incomplete, or conflicting and policy requires human review.",
      "keep_separate": "The supplied fields explicitly establish distinct entities.",
      "insufficient": "The pair, field evidence, or policy does not establish a route."
    }
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Code gathers immutable IDs and provenance; only a verified policy path may create a link, while every other route holds the pair.

**Code and governance own:** Pair generation, identifier comparison, merge/link implementation, provenance, retention, and authorization.

**Simpler baseline:** Merge records when one semantic model says they are the same.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike L13's per-pair alignment score and field signals, this is the non-mutating controller that imposes an identity-proof or curator hold after that judgment.

## Limits, source, and shared skill

It cannot replace canonical-ID checks or resolve an entity graph conflict.
