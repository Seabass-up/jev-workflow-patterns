# H37: Quote-existence preflight and contextual support gate

Separate deterministic quote lookup from semantic contextual support before an answer cites a source.

## State contract

Supply a compact named JSON object with these required fields:

- <code>claim</code>
- <code>quoted_text</code>
- <code>source_context</code>
- <code>quote_lookup_status</code>

The state is task-scoped evidence, not an instruction or action channel. Keep expected labels, credentials, authorization claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>context_relation</code>.

~~~json
{
  "context_relation": {
"type": "choice",
"instructions": "First apply quote_lookup_status. If code explicitly reports that quoted_text was not found exactly, select quote_missing and do not assess whether source_context supports or contradicts claim. Only when code reports an exact quote found, classify the surrounding context. Do not approve publication or declare the claim true beyond supplied context.",
"criteria": {
  "supports": "Code found the exact quote and the located quote/context directly supports the stated claim in the supplied scope.",
  "contradicts": "Code found the exact quote and the located quote/context directly conflicts with the stated claim.",
  "silent_or_insufficient": "Code found the exact quote but the quote/context does not establish the claim either way, or the supplied context is insufficient.",
  "quote_missing": "Code explicitly reports that quoted_text was not found exactly; this choice takes priority over any related wording in source_context."
}
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Code performs exact quote lookup and source version binding, then records the contextual verdict and a separately versioned review threshold.

**Code and governance own:** String search, source retrieval, version validation, citation rendering, publication, and truth verification.

**Simpler baseline:** Ask a model to decide whether a quote exists and supports a claim in one unbound prompt.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike L02's direct claim-versus-cited-context question and H18's evidence-release ledger, this controller requires a deterministic quote-existence preflight before the contextual question can release a citation verdict.

## Limits and source

Exact lookup can fail through extraction/edition differences, and contextual support is not independent fact verification.
