Reconsider an unexecuted proposed action when fresh evidence invalidates a stated precondition or changes its target.

## State contract

Supply a small, named JSON object. Required fields:

- `pending_action`
- `prior_state`
- `new_observation`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "How does `new_observation` affect the stated preconditions and target of `pending_action`, compared with `prior_state`? Do not execute or authorize the action.",
    "criteria": {
      "unchanged": "The new observation explicitly leaves every stated precondition and target unchanged.",
      "invalidated": "The new observation explicitly makes a stated required precondition false or impossible.",
      "replan_required": "The action may remain possible, but a stated target, scope, parameter, or relevant condition materially changed.",
      "insufficient": "The action, prior state, or new observation lacks enough information or conflicts."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code checks snapshot/revision identity before action. Anything other than `unchanged` or an uncertain response discards the pending proposal and returns to approved planning/review.

**Code and governance own:** State snapshots, exact preconditions, revision comparison, permissions, tools and all action execution.

**Baseline this improves on:** Reuse a planned action until its timer expires.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike H10's retraction of a delivered recommendation, this protects a still-pending, unexecuted proposal.

## Limits and sources

The model cannot prove state freshness or action authorization.
