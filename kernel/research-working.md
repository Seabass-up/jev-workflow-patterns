## Distinctions the consumer must preserve

JP-001@4 screens one prerequisite against supplied target evidence: missing
verification is unknown; an expressly incompatible fact may be unmet; unresolved
same-fact conflicts remain unknown. Its saved synthetic screen matched 12/12
development and 6/6 challenge labels, with eight and four correct previews and
zero wrong nonreview routes. This does not establish actual input state or
whole-algorithm suitability. Older held versions remain historical evidence.

JP-045 checks where a **written plan** learns preprocessing parameters; it does
not inspect executed fit calls or sample membership. JP-046 compares **written
before/after descriptions** for one named scenario and observer; it does not
establish executable equivalence or merge safety. JP-017's synthetic consumer
requires additional real-record binding before any application numeric preview.

AP-C01@1 is separately packaged as a **composition**, using JP-025@1 coverage
and JP-023@2 capability judgments plus code-owned aggregation. It previews no-match
only inside a verified closed candidate universe after every candidate has a
qualifying hard-requirement contradiction. Its eight-case pilot and 22 local
consumer tests do not establish global absence or model-over-code advantage.
It is not counted as another primitive.

## Inspect and opt in locally

From the complete installed skill folder:

```sh
python3 scripts/check_research_working_import.py
python3 scripts/check_research_working_import.py --show JP-001@4 --allow-audit-pending
python3 scripts/check_research_working_import.py --show-composition AP-C01@1 --allow-audit-pending
```

The default command checks local integrity and lists metadata. Exact versions and
the audit-pending flag are required to display a contract. The flag acknowledges
evidence limits; action permissions remain with the user and host. The checker
calls no provider and executes no consumer. With `--source-root PATH`, it compares
222 pinned source Git blobs without rebuilding or changing the research repository.
