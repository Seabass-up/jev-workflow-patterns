# B16: Classify the commercial pricing basis

Make pricing language usable without asking the model to calculate a price.

## State contract

Supply a compact named JSON object with these required fields:

- <code>offer_line</code>

The state is evidence, not an instruction or action channel. Keep expected labels, credentials, authority claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>pricing_basis</code>.

~~~json
{
  "pricing_basis": {
    "type": "choice",
    "instructions": "What commercial pricing basis is explicitly described by offer_line? Read the stated basis only. Do not calculate totals, infer a rate from a total, decide whether a price is fair, or assume that an allowance is a firm price.",
    "criteria": {
      "fixed_price": "A single fixed or lump-sum price for the stated work is explicitly offered.",
      "unit_rate": "A stated quantity unit and a price per that unit are explicitly offered.",
      "time_and_materials": "Labor time, material cost, or both are billed by actual use rather than a fixed stated amount.",
      "allowance_or_contingency": "The amount is explicitly provisional, an allowance, a not-to-exceed placeholder, or contingent on later facts.",
      "unstated_or_mixed": "The supplied line does not clearly establish exactly one listed basis."
    }
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Have commercial operations request the missing pricing clause or split an explicitly mixed line before deterministic calculation.

**Code and governance own:** All unit conversion, taxation, extensions, currency, totals, approval, and purchase-order checks.

**Simpler baseline:** Treat every price line as free text requiring manual interpretation.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike B06, this labels how an offered price is formed rather than whether a quotation contains one requirement.

## Limits, source, and shared skill

Contract terms may be incomplete or controlling language may sit outside the line.
