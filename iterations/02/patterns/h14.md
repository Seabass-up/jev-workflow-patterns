## State contract

Supply a small, named JSON object. Required fields:

- `document`
- `field_role`
- `candidate_spans`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "Which supplied span in `candidate_spans` is the value for `field_role` in `document`? Select only a listed span ID, `not_found`, or `ambiguous`; do not synthesize a value.",
    "criteria": {
      "s1": "Span s1 is the requested value.",
      "s2": "Span s2 is the requested value.",
      "s3": "Span s3 is the requested value.",
      "not_found": "No supplied span is the requested value.",
      "ambiguous": "Several spans fit or the role cannot be determined."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code checks the selected span's source revision, byte/character offsets and verbatim text, then normalizes only after validation. `not_found` expands candidate finding; `ambiguous` preserves candidates.

**Code and governance own:** Candidate discovery, offsets, text extraction, normalization, source authority and downstream writes.

**Baseline this improves on:** Let a generator produce a value or accept a regex's first match.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike H06's example-versus-real tool-argument guard, this validates a selected evidence span and its exact offsets before copying a value.

## Limits and sources

Candidate finding coverage and exact offset validation are host responsibilities.

[Source documentation](https://docs.typesafe.ai/cookbooks/pre_parsed_value_extraction_cookbook). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
