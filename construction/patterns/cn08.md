# CN08 — Closeout document type from its title and opening text

[Construction catalog]({{ '/construction/' | relative_url }}) · [Evaluation and limitations]({{ '/construction/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/construction.md)

Classify which closeout document type a submitted item's title and opening text describe, so the closeout checklist can be updated and lien waivers routed to accounting.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/construction/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Sorts a closeout package into the checklist's categories without a person opening every file, while validity, amounts, and legal effect stay with people and code.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `document_description`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

Review when confidence is below 0.8. With 6 options, that floor is equivalent to a top probability of 0.8333; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `CN08-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "document_description": "Title: Operation and Maintenance Manual, Rooftop Air Handling Units, Volume 2 of 3, submitted by Halvorsen Mechanical (halvorsenmech.example). Opening text: This volume contains the manufacturer's start-up, operating, and quarterly service instructions and the replacement parts list for the four rooftop units. The first tab reproduces the manufacturer's five-year compressor warranty, under which defective compressors will be replaced at no charge for five years from start-up. The second tab contains the installing contractor's marked-up duct shop drawings showing the final unit locations, which differ from the design drawings at the third unit."
}
```

Expected label: `operation_and_maintenance_manual`.

The document contains three types (service instructions, a warranty, and as-built markups), and the contract says that when more than one type is present the type the title states is selected; the warranty-first precedence order applies only when the title states none.

## Code-owned responsibilities

Code owns the closeout checklist and the count of received versus required items, the match of lien-waiver amounts and through-dates against pay applications, warranty start dates, and the file location; the label sorts documents only, and the owner's representative or counsel decides a waiver's sufficiency.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; an unknown label sends the document to the project engineer.

## Verification recipe

Compare labels with how the project engineer filed a completed project's closeout binder; review every lien waiver the label filed under another type.

This describes required verification work, not checks already performed.
