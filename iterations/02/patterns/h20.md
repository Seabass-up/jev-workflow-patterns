## State contract

Supply a small, named JSON object. Required fields:

- `rule`
- `case`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "eligible": {
    "type": "noul",
    "instructions": "Does `case` explicitly meet the low-stakes eligibility `rule`? Answer only from the supplied text. A yes is an advisory prediction, not permission to act.",
    "criteria": {
      "true": "The case clearly meets every stated condition of the rule.",
      "false": "A condition is absent, fails, conflicts, or cannot be established from the case."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code stores the raw probability, model/version, source revision and later independent adjudication. It computes coverage and calibration by fixed bins; it lowers automation or pauses it when results fail the predeclared target.

**Code and governance own:** Adjudication collection, labels, binning, statistical thresholds, action policy, data retention and deployment changes.

**Baseline this improves on:** Treat one probability or one smoke test as calibration.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike H12 repeat stability, this compares predictions with later independent outcomes instead of comparing the model to itself.

## Limits and sources

Four synthetic cases cannot establish calibration; no threshold change is authorized automatically.

[Source documentation](https://docs.typesafe.ai/cookbooks/consistency_noul_cookbook). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
