## State contract

Supply a small, named JSON object. Required fields:

- `draft_statement`
- `source_material`
- `calculation_record`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "What provenance mode is supported for `draft_statement` by `source_material` and `calculation_record`? Judge only the supplied evidence. Do not verify source authority or perform unstated calculations.",
    "criteria": {
      "verbatim_source": "The statement is directly stated in the supplied source material, allowing ordinary paraphrase.",
      "deterministic_derivation": "The statement follows from an explicitly supplied deterministic calculation record.",
      "model_inference": "The statement is a plausible interpretation or inference, but not directly stated or deterministically derived.",
      "unsupported_or_conflict": "The evidence is absent or directly conflicts with the statement."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Label inference as inference, attach a source/calc record to supported content, or remove/qualify unsupported claims.

**Code and governance own:** Verify quotations, calculations, source authority, freshness and answer delivery.

**Baseline this improves on:** Treat every fluent statement as a sourced fact.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike L02's citation-to-claim relation and L03's extracted field check, this labels how a planned answer assertion was obtained.

## Limits and sources

A provenance mode does not prove the source itself is true.

[Source documentation](https://docs.typesafe.ai/cookbooks/citation_check). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
