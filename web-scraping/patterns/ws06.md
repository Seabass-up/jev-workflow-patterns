# WS06 — Page change is structural or content-only for the extractor

[Web data catalog]({{ '/web-scraping/' | relative_url }}) · [Evaluation and limitations]({{ '/web-scraping/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/web-scraping.md)

Classify whether a change between two snapshots of a page alters the structure the extractor relies on, only the values it reads, or parts it does not read.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/web-scraping/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Routes extractor maintenance to a template fix, a data refresh, or nothing, instead of treating every diff as a breakage.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `extractor_fields`
- `previous_excerpt`
- `current_excerpt`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

```json

    "type": "choice",
    "instructions": "First, if any required field (`extractor_fields`, `previous_excerpt`, `current_excerpt`) is absent, empty, or lacks the information needed for this judgment, select unknown before considering other labels. `extractor_fields` lists the fields the extractor reads and where in the page it reads each one. `previous_excerpt` and `current_excerpt` are the corresponding markup or rendered text from before and after the change. Classify the change as it affects those fields. A change that renames, moves, removes, nests differently, or replaces the elements or labels that carry an extractor field is structural. A change that leaves those elements in place and alters only the values inside them is content-only. A change confined to parts of the page that no extractor field is read from, such as advertisements, footers, or unrelated sections, is unrelated.     "criteria": {

      "content_only_change": "The elements carrying each extractor field are unchanged and only the values inside them differ.",
      "unrelated_change": "The differences lie only in parts of the page that no extractor field is read from.",
      "unknown": "Required evidence is missing, contradictory, or does not support a determinate classification."
    }
  }
}
```

## Policy recorded with its option count

Review when confidence is below 0.8. With 4 options, that floor is equivalent to a top probability of 0.85; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `WS06-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "extractor_fields": [
    "title: text of h1.product-title",
    "price: text of span.price-current inside div.buy-box",
    "availability: text of span.stock-state inside div.buy-box"
  ],
  "previous_excerpt": "<h1 class=\"product-title\">Norwood 3-Seat Sofa, Slate</h1><div class=\"buy-box\"><span class=\"label\">Price</span><span class=\"price-current\">$899.00</span><span class=\"stock-state\">In stock</span></div><footer>Copyright 2025 Hearth &amp; Co</footer>",
  "current_excerpt": "<h1 class=\"product-title\">Norwood 3-Seat Sofa, Slate</h1><div class=\"buy-box\"><span class=\"label\">Now</span><span class=\"price-current\">$849.00</span><span class=\"stock-state\">In stock</span></div><footer>Copyright 2026 Hearth &amp; Co - Cookie settings</footer>"
}
```

Expected label: `content_only_change`.

Every element an extractor field is read from (h1.product-title, span.price-current and span.stock-state inside div.buy-box) is still present in the same place with the same class, and only the price value inside one of them changed. The renamed span.label and the footer are not read by any field, so the visible label rename is not a change to an element that carries a field.

## Code-owned responsibilities

Code computes the diff, runs the extractor against the current snapshot to confirm what actually parses, versions the template, and schedules the fix; the label only routes the diff.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; structural_change opens a maintenance task.

## Verification recipe

Compare labels with the maintainer's disposition of a quarter of change alerts; review structural changes the label called content-only first.

This describes required verification work, not checks already performed.
