# L22: Classify question-answer directness

Assess whether a candidate answer actually addresses the user's question, separately from whether evidence supports it.

## State contract

Supply a compact named JSON object with these required fields:

- <code>user_question</code>
- <code>candidate_answer</code>

The state is task-scoped evidence, not an instruction or action channel. Keep expected labels, credentials, authorization claims, and external-action arguments outside it.

## Exact typed Jev question contract

Question IDs: <code>answer_directness</code>.

~~~json
{
  "answer_directness": {
"type": "choice",
"instructions": "How directly does candidate_answer answer user_question? Judge relevance/completeness of the response to the question only. Do not judge factual truth, citation support, safety, or tone.",
"criteria": {
  "directly_answers": "The answer addresses the asked question with the requested kind of information and no material omission apparent from the question itself.",
  "partially_answers": "The answer addresses part of the question but leaves a material asked component unresolved.",
  "tangential": "The answer discusses a related topic but does not provide the requested answer.",
  "does_not_answer": "The answer refuses, changes the subject, or gives no substantive response to the question."
}
  }
}
~~~

## Code-owned decision envelope

**Follow-up proposal:** Route partial/tangential outputs to bounded clarification or answer revision; perform evidence verification separately.

**Code and governance own:** Truth checking, citation checks, response generation, user messaging, and delivery.

**Simpler baseline:** Have a human assess directness of every generated response.

## Uncertainty and distinctness

Provisional synthetic screening only; model output is advisory.

**Why this is not a renamed earlier pattern:** Unlike L16's pre-answer corpus answerability and L11's source-coverage score for an answer plan, this checks the finished answer's directness to the question without assessing evidence.

## Limits and source

A direct answer can still be wrong, unsafe, poorly sourced, or inappropriate.
