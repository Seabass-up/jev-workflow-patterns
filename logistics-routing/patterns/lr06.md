# LR06 — Hazardous or temperature-controlled declaration in order text

[Logistics routing catalog]({{ '/logistics-routing/' | relative_url }}) · [Evaluation and limitations]({{ '/logistics-routing/evaluation/' | relative_url }}) · [Kernel reference module](https://raw.githubusercontent.com/Seabass-up/jev-workflow-patterns/main/skills/jev-question-kernel-catalog/references/logistics-routing.md)

Classify whether order text itself declares hazardous goods, temperature-controlled goods, both, or neither.

This is a proposed, bounded text judgment. Consult the [evaluation record]({{ '/logistics-routing/evaluation/' | relative_url }}) for observed results; the fixture labels below are intended outputs.

## Proposed benefit

Flags declarations to reconcile with the product master before a vehicle and driver are assigned, without letting the model classify goods for regulatory purposes.

This is a proposed benefit, not an observed outcome. All fixtures on this page are synthetic.

## Required named state

Supply the following named fields as the evidence packet:

- `order_text`

Code deterministically returns `unknown` without invoking Jev when any required named field is absent or empty; the model is not the required-field gate. The live missing-input case below probes the contract wording, not that gate.

## Policy recorded with its option count

Review when confidence is below 0.8. With 5 options, that floor is equivalent to a top probability of 0.84; a threshold is not portable to a contract with a different option count. These values are provisional workflow policy, not calibration.

## Complete synthetic example

This is fixture `LR06-4`, from the **challenge** split. Its author received the question contract without the design fixtures or model results; the expected label is an authored interpretation of the contract, not a Jev prediction.

```json
{
  "order_text": "These are not dangerous goods: the cells ship fully discharged and packed under the small-quantity exemption, so no hazard labels apply. Keep the crates between 5 and 25 degrees C and out of direct sun for the whole transit."
}
```

Expected label: `temperature_controlled_declared`.

The text states the goods are not dangerous goods, which is a negation rather than a hazard declaration, and the contract forbids inferring a hazard from a product mention like 'cells' alone. It does state that the goods must stay within a temperature range, so it declares temperature control and no hazard.

## Code-owned responsibilities

Code looks up every item in the product master for its regulatory class and temperature band, applies vehicle and driver qualification rules, and treats a declaration as a flag to reconcile, not as the classification of record.

The judgment is advisory. Code and the responsible person retain control of exact identifiers, data access, state changes, and consequential verification.

## Bounded follow-up

None; a mismatch between the label and the product master goes to the shipping desk.

## Verification recipe

Compare labels with the product master's flags for the same orders; investigate every order the text declared that the master did not, and the reverse.

This describes required verification work, not checks already performed.
