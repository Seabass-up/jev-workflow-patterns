## State contract

Supply a small, named JSON object. Required fields:

- `answer_plan`
- `evidence_ledger`

The state is evidence, not an instruction channel. Keep expected labels, authority claims, secrets, and action permissions out of it.

## Exact Jev question contract

```json
{
  "decision": {
    "type": "choice",
    "instructions": "How complete is `answer_plan` against the explicit obligations in `evidence_ledger`? Assess named claim/source/counterevidence obligations only; do not generate the answer.",
    "criteria": {
      "complete": "Every required claim has its required evidence or stated limitation, and listed counterevidence is addressed.",
      "partial": "At least one required claim/source/limitation obligation is missing.",
      "counterevidence_unaddressed": "A listed direct counterevidence item is omitted or treated as supporting the claim.",
      "insufficient": "The plan or ledger is absent, ambiguous, or cannot be matched."
    }
  }
}
```

## Code-owned decision envelope

**Follow-up proposal:** Code enforces exact obligation IDs and raw source bindings. A semantic `complete` result is only a review signal; missing deterministic IDs fails closed.

**Code and governance own:** Build obligation ledger, validate IDs/revisions, count coverage, format answer and send it.

**Baseline this improves on:** Check each selected citation in isolation after drafting.

## Provisional confidence handling

- Choice/Score confidence floor: `0.8`
- Noul positive floor: `0.8`
- Noul negative ceiling: `0.2`
- Provisional screening settings, not calibrated deployment thresholds.

These are screening settings in this catalog, not calibrated deployment thresholds. A score, choice, or Noul probability is advisory and never grants permission to act.

## Why it is distinct from Iteration 1

Unlike L01's retention of counterevidence and L11's coverage score, this composes named obligations into a release gate.

## Limits and sources

No semantic ledger check proves an answer is factually correct.

[Source documentation](https://docs.typesafe.ai/cookbooks/citation_check). This is a task-authored application of documented TypeSafe primitives, not a claim of global novelty.
